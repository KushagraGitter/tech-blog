Survey on LLM-Based Autonomous Agents: The Architecture Handbook

October 11, 2026 · 7 min read
AISurveyArchitecture

We've covered 9 individual ideas. Now we zoom out: What are all the building blocks of a modern AI agent, and how do they fit together?

That's what this survey does. It's the handbook.

The Universal Agent Architecture

Most agent designs have these components:

  1. Perception: The agent observes the world (sensors, APIs, text input).
  2. Memory: The agent stores what happened.
  3. Planning: The agent decides what to do next.
  4. Action: The agent does something (calls an API, runs code, talks to a human).
  5. Reflection: The agent observes the result and updates its understanding.

Loop back to step 1. This is the cycle that powers every agent.

Building Block 1: Planning (The Brain)

Chain-of-Thought: Step-by-step reasoning.
Tree of Thoughts: Explore multiple paths; backtrack if needed.
ReAct: Interleave reasoning with action.

When to use which:**

  • Simple problems → CoT
  • Complex problems with multiple paths → ToT
  • Problems needing real-time action → ReAct

Building Block 2: Tool Use (The Hands)

Toolformer: Learn which tools to use.
HuggingGPT: Orchestrate multiple specialized models.
ReAct: Take actions and observe results.

When to use which:**

  • Limited, curated tools → ReAct
  • Learn to use tools automatically → Toolformer
  • Orchestrate many specialized models → HuggingGPT

Building Block 3: Memory (The Record)

Short-term: What just happened (last few messages).
Long-term: What happened before (vector database, skill library).
Meta-memory: Reflections on what you learned.

Implementation:**

  • Vector database for semantic search ("Recall tasks similar to this").
  • Skill library (like Voyager) for reusable procedures.
  • Episodic memory for stories ("Remember when X happened?").

Building Block 4: Learning & Improvement (The Growth)

Reflection: Learn from feedback without retraining.
Voyager: Continuous learning with goal generation.
In-context learning: Improve within a conversation.

When to use which:**

  • Quick improvement on a task → Reflection + in-context learning
  • Long-term, open-ended improvement → Voyager-style curriculum
  • Offline improvement → Fine-tuning (not covered here but important)

Building Block 5: Multi-Agent Coordination (The Team)

Generative Agents: Emergent behavior from individual agents.
AutoGen: Agents collaborating through conversation.
Swarms: Many simple agents solving complex problems together.

When to use which:**

  • Agents with individual goals → Generative Agents
  • Agents with complementary roles → AutoGen
  • Scale to hundreds of agents → Swarms (research frontier)

What Makes a Good Agent

1. Clear decomposition: Break goals into sub-tasks (HuggingGPT, AutoGen)

2. Good memory: Remember what worked (Voyager's skill library, Generative Agents' episodic memory)

3. Explicit feedback loops: Observe results and adjust (Reflection, ReAct)

4. Graceful degradation: If a tool fails, try another path (Tree of Thoughts, ReAct with backtracking)

5. Bounded execution: Know when to stop (termination conditions, max tokens, user approval)

Design Decisions: A Checklist

When building an agent, ask:

  • Planning: Does it need to explore multiple options (ToT) or just reason linearly (CoT)?
  • Actions: How many tools? How often does it act?
  • Memory: How long? Vector DB or skill library or both?
  • Learning: Improve on the fly (Reflection) or long-term (Voyager)?
  • Multi-agent: Solo agent or team? If team, who talks to whom?
  • Safety: Who approves major actions? What's the fallback?

The Frontier: Open Questions

1. Scaling: Do these techniques work with 100+ agents? 1000+?

2. Safety: When agents get smarter, how do we keep them aligned?

3. Emergence: Multi-agent systems surprise us (Generative Agents throwing a birthday party). Can we predict or control it?

4. Real-world deployment: These papers mostly work in simulation or narrow domains. How do they work in messy, real-world environments?

5. Efficiency: Token cost is high. Can we get the same results with fewer calls?

What You Take Away

  • Modern agents combine 5 building blocks: planning, tools, memory, learning, and (optionally) multi-agent coordination.
  • Each building block has design trade-offs (fast vs. accurate, cheap vs. capable, etc.).
  • The papers you've learned aren't competing — they're pieces of a larger puzzle.
  • Combining them intelligently produces agents that work in the real world.
  • The frontier isn't solved — scaling, safety, and emergence are still open problems.

Next Steps

To learn more:

  • Implement each technique in a small project.
  • Combine 2-3 techniques and see how they interact.
  • Read the full papers (arXiv links below) to understand the nuances.
  • Study frameworks that implement these ideas: LangChain, AutoGen, CrewAI, LangGraph.

To build agents:

  • Start simple: CoT + one tool + reflection.
  • Add complexity: ToT, more tools, memory, multi-agent.
  • Measure success: Does the agent complete tasks? Is it cost-effective? Is it safe?
