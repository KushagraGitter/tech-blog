ReAct: When AI Thinks AND Acts

October 11, 2026 · 5 min read
AIAgentsPrompting

Chain-of-thought taught AI models to reason. ReAct taught them to reason, then take action, then observe what happened, then reason again.

It's the loop that powers every modern AI agent.

The Problem with Pure Reasoning

An AI that only reasons is like a person stuck in their head with no way to act. You can ask it "What's the weather right now?" and it'll reason its way through "I don't have real-time data" — but it can't actually check the weather.

Chain-of-thought solved reasoning. But the real world needs reasoning + action.

The ReAct Loop

ReAct stands for "Reasoning + Acting." The idea is beautifully simple:

  1. Thought: The AI reasons about what to do next.
  2. Action: The AI calls a tool or API (search the web, check email, run code).
  3. Observation: The AI sees the result and updates its understanding.
  4. Repeat: Loop back to Thought with new information.

Example: You ask "Who won the 2024 Super Bowl?"

  • Thought: "I don't know who won recently. I should search for this."
  • Action: Search("2024 Super Bowl winner")
  • Observation: "Kansas City Chiefs defeated San Francisco 49ers, 25-22"
  • Thought: "Now I have the answer. I can respond."

This is what makes ChatGPT's "browsing" and Claude's "tool use" actually work. It's ReAct.

Why It's Better Than the Alternative

Before ReAct, most systems had two paths:

  • Direct reasoning: "Based on what I know, the answer is X." (Often wrong for current events.)
  • External search: Always query a database first, then answer. (Wastes time and tokens on simple questions.)

ReAct is smarter: the AI decides when it needs to act. For "What's 2+2?" it just reasons. For "What's happening in tech news today?" it searches. For "Send me an email summary of my inbox" it reasons about what to search for, then takes actions, then aggregates.

The Challenges

ReAct sounds simple, but there are three hard problems:

  1. Tool selection: How does the AI know which tool to call? You have to give it a clear list of what's available, and the AI has to choose correctly.
  2. Error handling: What if the search fails? What if the API is down? The model has to reason about that and try something else.
  3. Token cost: Every observation gets added back to the context. A 5-step ReAct loop can double your token usage.

Where ReAct Is Winning

  • Customer support agents: "Check the order status" → search database → observe → respond.
  • Data analysis: "Summarize my sales data" → query database → observe → calculate → respond.
  • Web agents: "Buy me a plane ticket" → search flights → click result → fill form → pay.
  • Coding: "Debug this error" → run code → observe crash → edit file → run again.

The Future: Self-Correcting Agents

ReAct's real superpower is that it can verify and correct itself. If the action didn't produce the right result, the AI can loop back and try something different — without human intervention.

That's the foundation for agents that actually work autonomously.

What You Take Away

  • Reasoning without action is incomplete.
  • The best AI agents alternate between thinking and doing.
  • Every tool you expose to an AI needs to be clearly described (what it does, when to use it, what it returns).
  • The loop continues until the goal is achieved — or until it fails and gives up.
